Detailed Description

Shared context for the example flows (metadata + baseline scans).

OOP wrappers for the example flows to keep a single main entrypoint.

Responsible for loading the JSON/PCAP pair once, caching baseline scans, and handing out deep-copied manipulators so individual demos can mutate data without affecting one another. Provides a single source of truth for sensor metadata across examples.
