Detailed Description

Minimal Qt UI wrapper for running PCAP/JSON processing demos.

Provides drag-and-drop support plus browse buttons for selecting files, then triggers processing and displays textual results. Keeps only UI state; heavy data loading/manipulation is delegated to backend logic (not shown here).
