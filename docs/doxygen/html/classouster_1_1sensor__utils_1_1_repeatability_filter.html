Apply the filter in-place to a collection of scans.

Parameters
scansMutable scans to operate on.
infoSensor metadata providing dimensions/calibration.

Implementations may assume all scans share dimensions from info. Filters are free to mutate range fields (and other channels if needed) but should leave metadata intact. No ownership of info is taken. Callers expect idempotent application over the provided scan vector (state should not be preserved across apply() calls unless documented).

Implemented in ouster::sensor_utils::KalmanRangeFilter, ouster::sensor_utils::NormalGuidedSmoother, ouster::sensor_utils::PlanaritySmoother, and ouster::sensor_utils::StatisticalOutlierFilter.
