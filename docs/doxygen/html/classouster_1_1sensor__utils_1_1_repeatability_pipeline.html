Detailed Description

Simple orchestrator that applies a series of repeatability filters.

Filters are executed in the order they are added. Each filter mutates the working copy of scans in-place; the original input vector is preserved by copying it prior to processing. The pipeline stores the sensor metadata so filters receive a stable reference even if the caller discards theirs. The pipeline itself holds no persistent scan state between runs.
