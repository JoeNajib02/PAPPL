Detailed Description

Serialize repeatability metrics to human-readable formats.

Provides lightweight CSV/JSON dumps suitable for plotting or quick inspection. Does not perform directory creation; callers should ensure the parent path exists. All values are written verbatim (no unit conversion); callers should pre-scale if alternate units are desired.
