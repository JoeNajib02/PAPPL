Detailed Description

Rejects ranges that violate a global z-score threshold.

Computes mean/stddev over all valid ranges per scan, zeroing points that are either below min_range_mm or beyond z_thresh * stddev from the mean. The threshold is recomputed for each scan independently; no temporal smoothing.
